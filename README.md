# CS320 Enhanced Service Application

This repository branch contains my CS320 artifact used in my CS499 Computer Science Capstone at Southern New Hampshire University.

## Overview

This project is an enhanced version of a service-based Java application originally developed in **CS320: Software Testing, Automation, and Quality Assurance**. The original project focused on object-oriented design, validation logic, and service-layer operations for contacts, tasks, and appointments.

For my capstone, I used this artifact for both the **Software Design and Engineering** and **Databases** categories because it provided a strong foundation for demonstrating architectural improvement, testing, persistence, and relational data design.

## Capstone Categories Represented

- **Software Design and Engineering**
- **Databases**

## Software Engineering Enhancements

For the software engineering enhancement, I refactored the project into a more professional layered architecture by separating the code into:

- model layer
- service layer
- repository layer
- database layer
- exception handling layer

This change improved maintainability, separation of concerns, scalability, and readability. I also integrated Maven and JUnit testing to support better structure and repeatable testing practices.

## Database Enhancements

For the database enhancement, I extended the project into a relational SQLite application. The enhanced version includes:

- persistent storage using SQLite
- relational schema for contacts, tasks, and appointments
- foreign key relationships
- indexed lookups
- prepared statements for safer database interaction
- repository methods for retrieving related records by contact ID

These changes transformed the application from an in-memory academic exercise into a stronger database-driven system.
