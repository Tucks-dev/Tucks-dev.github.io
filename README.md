# CS340 Enhanced Grazioso Salvare Dashboard

This repository branch contains my CS340 artifact used in my CS499 Computer Science Capstone at Southern New Hampshire University.

## Overview

This project is an enhanced version of the Grazioso Salvare Dashboard originally developed in **CS340: Advanced Programming Concepts**. The original dashboard connected animal shelter data to an interactive application that allowed users to filter animals and view them in a data table, pie chart, and map.

For my capstone, I selected this artifact for the **Algorithms and Data Structures** category because it provided a strong opportunity to improve filtering logic, reduce repeated processing, and make the system more efficient and maintainable.

## Capstone Category Represented

- **Algorithms and Data Structures**

## Enhancements

The original version of the dashboard used repeated filtering logic and performed summary calculations after retrieving data into the application. For the capstone enhancement, I improved the artifact by:

- centralizing rescue filter definitions into a reusable structure
- creating reusable query-building logic
- adding aggregation support for summary calculations
- reducing repeated filtering logic
- improving maintainability by refactoring notebook-style code into a standalone Python application
- adding fallback support for local testing when the original remote MongoDB host was unavailable

These changes improved the efficiency and organization of the application while preserving the original functionality.
